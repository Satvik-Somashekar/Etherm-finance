# Query accuracy evaluation

Generated by `evaluation/evaluate.py` against `http://localhost:8084`, as of 2026-10-25, over 5 synthetic users. Ground truth is computed in Python from the raw FI JSON, independently of the Java normalisers and compute engine. Each time-bound question is asked for 8 periods for every user.

The dev set was used to find and fix parser gaps; the held-out set was written before those fixes, so it is the fairer estimate for unseen wording.

Read these numbers with their limits. The questions come from 67 answerable phrasings and 14 out-of-scope ones, multiplied across periods and users, so wording diversity is far smaller than the question count. The parser is rule-based and was written by the same people who wrote the questions. The held-out misses were visible when the dev fixes were made, and one general rule (insurance plus a cost word means premiums) fixed a held-out miss as well. See BASELINE.md for the run before the fixes.
